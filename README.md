SUNLINE: The Solenne Job is an original top-down 2D open-city action game set in Solenne. Explore on foot or steal and drive cars, dodge or fight police pursuit through a 0–5 star wanted system, and aim and shoot with the mouse. Follow a four-job story chain from your contact, radio operator Mara Vela: recover a dead-drop tape, steal an Aurelia GT, and broadcast the truth about the city's stolen shoreline, leading to a finale and free roam.

Built with vanilla JavaScript and Canvas 2D — no libraries, no build step, no downloads, and no external fonts or assets. Every visual is drawn in code, and the game makes zero network requests, so it plays fully offline in desktop Chrome.

**Tech note:** Progress (cash and completed jobs) saves automatically to localStorage.

## Controls

- **WASD / arrows:** move or drive.
- **E:** enter, steal, or exit a car.
- **Mouse / left click:** aim and fire.
- **F:** talk or interact.
- **M:** city map.
- **Esc / P:** pause.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```

or open `game/index.html` directly in desktop Chrome — no server or build step is needed.
